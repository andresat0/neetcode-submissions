# NeetCode Coding Practice

I use [NeetCode](https://neetcode.io) to practice data structures and algorithms in Python and prepare for coding interviews. I share my submissions here as a record of my practice and the different approaches I try.

## What I am practicing

I am building fluency with arrays, strings, hash maps, sets, and problem-solving patterns. My goal is to explain why an approach works, reason about its time and space complexity, and become more comfortable implementing solutions independently.

## Multiple attempts

**This repository includes multiple attempts at some problems.** I keep those submissions to show how I work through a problem and revise my approach. Earlier attempts may contain debug prints, extra steps, or less efficient code.

I treat this repository as a practice archive. A numbered submission is not a claim that it is my best or most efficient solution, and I do not include a verified acceptance-status label for each file.

## Running the code

I write these submissions for NeetCode's problem-specific execution environment. Files generally contain a `Solution` class and may rely on imports supplied by the platform, such as `List` from `typing`. To run a submission locally, I would need to provide the relevant imports, test inputs, and a call to its method.
